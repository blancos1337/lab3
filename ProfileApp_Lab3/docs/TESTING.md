# Проверка проекта

## Автоматические тесты

Unit-тесты находятся в `app/src/test`. Они проверяют значения модели `User`
и вспомогательные методы `NameFormatter`.

После настройки Gradle в Android Studio можно запустить задачу `test` или
выполнить `./gradlew test` при наличии Gradle Wrapper.

## Ручная проверка интерфейса

- Экран открывается без ошибок.
- Имя меняется при вводе текста.
- Кнопка сброса возвращает исходное имя.
- Подписка увеличивает, а отписка уменьшает число подписчиков.
- Счётчик увеличивается при каждом нажатии.
- Переключение темы меняет цветовую схему.
- На небольшом экране содержимое можно прокручивать.
