# Архитектура приложения

Проект использует простое разделение на три области:

- `data` — модель пользователя и значения профиля по умолчанию.
- `ui` — экран и небольшие переиспользуемые Compose-компоненты.
- `util` — небольшие функции обработки строк, не зависящие от интерфейса.

`MainActivity` создаёт Compose-контент и передаёт экрану состояние темы.
`ProfileScreen` управляет локальным состоянием подписки, числа подписчиков,
счётчика нажатий и редактируемого имени. Отрисовка вынесена в компоненты.

Для учебного приложения состояние хранится через `remember`. Для более крупного
приложения можно рассмотреть ViewModel и сохранение данных между запусками.
