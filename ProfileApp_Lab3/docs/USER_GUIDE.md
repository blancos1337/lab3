# Руководство пользователя

1. Откройте приложение — отобразится карточка профиля.
2. В поле «Имя и фамилия» введите новое отображаемое имя.
3. Нажмите «Сбросить», чтобы вернуть исходное имя.
4. Нажмите «Подписаться» — надпись кнопки и число подписчиков изменятся.
5. Нажмите кнопку «+», чтобы увеличить счётчик нажатий.
6. Переключите тему в верхней части экрана.

Все изменения являются демонстрационными и хранятся в памяти текущего экрана.
После полного перезапуска приложения значения возвращаются к исходным.
