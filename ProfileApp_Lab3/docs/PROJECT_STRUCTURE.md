# Структура исходного кода

- `MainActivity.kt` — точка входа Android-приложения.
- `data/User.kt` — модель данных профиля.
- `data/ProfileDefaults.kt` — значения профиля по умолчанию.
- `ui/ProfileScreen.kt` — композиция главного экрана и состояние.
- `ui/components/` — отдельные визуальные компоненты.
- `ui/theme/Theme.kt` — цветовые схемы Compose.
- `util/NameFormatter.kt` — нормализация и объединение имени.
- `src/test/` — автоматические unit-тесты.
