# Заметки по интерфейсу

Интерфейс построен на Material 3. Основные элементы расположены вертикально,
чтобы экран оставался удобным на устройствах с разной высотой. Для карточки
счётчика используется цвет `surfaceVariant`, а для разделения информации и
элементов управления — `HorizontalDivider`.

Круглый аватар создаётся с помощью `CircleShape` и `clip`. Состояние подписки
анимирует цвет и небольшой масштаб кнопки. Светлая и тёмная схемы описаны
отдельно в `ui/theme/Theme.kt`.
