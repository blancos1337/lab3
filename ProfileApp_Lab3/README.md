## Описание проекта
Учебное Android-приложение с экраном профиля пользователя. Проект демонстрирует базовые компоненты Jetpack Compose, применение `Modifier`, управление состоянием и интерактивность Material 3.

## Реализованные функции
- Круглый аватар с иконкой пользователя.
- Имя, статус и число подписчиков.
- Кнопка подписки и отписки.
- Изменение количества подписчиков при переключении подписки.
- Редактирование имени через `TextField`.
- Сброс имени к исходному значению.
- Счётчик нажатий с кнопкой `+`.
- Анимация цвета и масштаба кнопки подписки.
- Переключение светлой и тёмной темы.
- KDoc-комментарии и Preview для основных компонентов.

## Технологии
- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL
- Минимальная версия Android: API 24
- Compile SDK: 35
- JDK: 17

## Как открыть и запустить
1. Распакуйте архив проекта.
2. Запустите Android Studio.
3. Выберите **Open** и укажите корневую папку `ProfileApp` (в ней находятся `settings.gradle.kts` и `build.gradle.kts`).
4. Дождитесь синхронизации Gradle. При запросе установите Android SDK Platform 35 и используйте JDK 17.
5. Создайте или выберите Android-эмулятор либо подключите Android-устройство с включённой отладкой по USB.
6. Нажмите **Run**.
