# Кодекс поведения

Участники проекта общаются уважительно и конструктивно. Не допускаются
оскорбления, травля, дискриминация и публикация чужих персональных данных.

При обсуждении ошибок описывайте проблему по существу, прикладывайте шаги
воспроизведения и ожидаемый результат. Поддерживайте дружелюбную учебную среду.
