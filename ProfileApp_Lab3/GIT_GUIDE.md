# Публикация проекта в GitHub

1. Создайте новый пустой репозиторий на GitHub, например `ProfileApp-Lab3`.
2. Откройте терминал в корневой папке проекта (там, где лежит `settings.gradle.kts`).
3. Выполните команды:

```bash
git init
git add .
git commit -m "Создан проект экрана профиля на Jetpack Compose"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ProfileApp-Lab3.git
git push -u origin main
```

4. Замените `ВАШ_ЛОГИН` на свой логин GitHub.
5. Вставьте ссылку на репозиторий в отчёт или покажите её преподавателю.

## Пример последовательности коммитов

Если работа выполняется поэтапно, можно зафиксировать изменения отдельными коммитами:

- `Создан каркас Android Compose проекта`
- `Добавлены модель пользователя и компоненты профиля`
- `Реализовано редактирование имени и подписка`
- `Добавлены счётчик, анимация и переключение темы`
- `Добавлена документация и отчёт`

Не создавайте фиктивные коммиты задним числом: история Git должна отражать фактическую работу.
