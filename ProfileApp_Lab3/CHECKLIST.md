# Проверка соответствия методичке

| Требование | Где реализовано | Что проверить перед сдачей |
|---|---|---|
| Круглый аватар 120 dp | `ui/components/Avatar.kt` | Иконка отображается по центру круга |
| Имя, статус, подписчики | `ui/components/ProfileInfo.kt` | Данные видны на экране |
| Отступы, размеры, выравнивание через Modifier | Все UI-компоненты | Интерфейс не обрезается на экране эмулятора |
| Разделитель | `ui/ProfileScreen.kt` | Линия находится между профилем и вводом имени |
| Подписка / отписка | `ui/ProfileScreen.kt`, `ActionButtons.kt` | Текст меняется после нажатия |
| Счётчик и кнопка + | `ui/ProfileScreen.kt` | Число увеличивается после нажатия |
| TextField для имени | `ui/ProfileScreen.kt` | Имя над полем меняется во время ввода |
| Сброс имени | `ui/ProfileScreen.kt`, `ActionButtons.kt` | Возвращается «Денис Черемисов» |
| Preview | Файлы компонентов и темы | Предпросмотр доступен в Android Studio |
| Анимация кнопки | `ui/ProfileScreen.kt`, `ActionButtons.kt` | Цвет и масштаб плавно меняются |
| Переключение темы | `MainActivity.kt`, `ui/theme/Theme.kt` | Переключатель меняет цветовую схему |
| KDoc | Kotlin-файлы | Комментарии описывают назначение и параметры |
| README и отчёт | `README.md`, `REPORT.md` | Вписаны данные студента, добавлен скриншот |
| Git / GitHub | `GIT_GUIDE.md` | Создать реальный репозиторий и загрузить проект |

## Важно

Архив содержит исходный проект и документацию. Он не содержит подтверждения успешной сборки на конкретном компьютере и реального скриншота работающего приложения: это нужно получить после запуска в Android Studio. Перед сдачей обязательно выполните сборку и пройдите пункты проверки выше.
